# Детекция и сегментация планктонных организмов

Сессионная работа по компьютерному зрению. Исследованы фотографии планктона, показаны аугментации, сравниваются предобученные YOLO11n и Faster R-CNN, а также GrabCut и SAM 2.1.

## Запуск

- Python 3.11; зависимости — `requirements.txt`. Для работы с GPU должна быть установлена совместимая версия PyTorch с CUDA.
- Положите исходные фотографии в `data/raw/`. Папка `results/` не заменяет исходный датасет.
- Откройте `session_work_plankton.ipynb` в JupyterLab, выберите установленное окружение и запустите.
- При первом запуске предобученных моделей могут скачиваться веса.

## Полученные результаты

В общем наборе 189 файлов, из них 21 по названиям похож на производные кропы. Для сравнения детекторов отобраны 8 исходных снимков из 168. Выполнено 96 запусков моделей, сохранено 504 предсказанных рамки. Для сегментации проверены 11 прямоугольников четырёх снимков, получено по 11 масок GrabCut и SAM 2.1.

- `results/eda/` — изображения для обзора данных;
- `results/augmentations/` — варианты аугментаций;
- `results/detections/` — фотографии с рамками двух моделей;
- `results/segmentation/` — маски и наложения на исходные фотографии;
- `results/tables/detection_runs.csv`, `detection_boxes.csv`, `bbox_stability.csv`, `detection_summary.csv` — результаты детекции;
- `results/tables/segmentation_results.csv`, `segmentation_summary.csv` — результаты сегментации;
- `results/tables/eda_review.csv`, `detection_review.csv`, `segmentation_review.csv` — визуальные наблюдения по сохранённым изображениям.

Время работы моделей зависит от окружения и повторного запуска. Отсутствует эталонная разметка, поэтому полученные IoU между предсказаниями и число рамок не являются измерением истинной точности.
